# Gemini Watermark Remover

A tool to remove SynthID watermarks from images generated by Google Gemini AI.

**Credit**: This skill is based on [GeminiWatermarkRemoveSkill](https://github.com/kevintsai1202/GeminiWatermarkRemoveSkill) by Kevin Tsai.

## Installation

### Method 1: Install via add-skill (Recommended)

```bash
npx add-skill lazylagom/imlazy-skills --skill gemini-image-watermark-remove
```

### Method 2: Direct execution (without installation)

```bash
npx gemini-image-watermark-remove image.png
```

### Method 3: Local development/testing

```bash
# Clone the repository
git clone https://github.com/lazylagom/imlazy-skills.git
cd imlazy-skills/skills/gemini-image-watermark-remove

# Install dependencies
pnpm install

# Run
node scripts/remove-watermark.js image.png
```

## Usage

### Basic Usage

The simplest usage. Output file is automatically created as `image_clean.png`.

```bash
npx gemini-image-watermark-remove image.png
```

### Specify Output File Path

```bash
# Save with specific filename
npx gemini-image-watermark-remove image.png -o clean.png

# Save to different directory
npx gemini-image-watermark-remove image.png -o ./output/result.png
```

### Select Mask Mode

Mask size is automatically selected based on image dimensions, but you can manually specify it.

```bash
# Force small mask (for images ≤1024px)
npx gemini-image-watermark-remove image.png -m small

# Force large mask (for images >1024px)
npx gemini-image-watermark-remove image.png -m large

# Auto-detect (default)
npx gemini-image-watermark-remove image.png -m auto
```

### Adjust Alpha Gain

If the watermark is not removed well, try increasing the gain value.

```bash
# Default removal strength
npx gemini-image-watermark-remove image.png -g 1.0

# Stronger removal (when watermark appears darker)
npx gemini-image-watermark-remove image.png -g 1.5

# Maximum strength (caution: may degrade image quality)
npx gemini-image-watermark-remove image.png -g 2.5
```

### Combine Multiple Options

```bash
npx gemini-image-watermark-remove input.png -o output.png -m large -g 1.5
```

### Batch Processing (Process Multiple Images)

**Linux/Mac:**
```bash
for file in *.png; do
  npx gemini-image-watermark-remove "$file"
done
```

**Windows (PowerShell):**
```powershell
Get-ChildItem *.png | ForEach-Object {
  npx gemini-image-watermark-remove $_.Name
}
```

## Options Reference

| Option | Description | Default | Example |
|--------|-------------|---------|---------|
| `-o, --output` | Specify output file path | `<filename>_clean.<ext>` | `-o result.png` |
| `-m, --mode` | Mask mode: `auto`, `small`, `large` | `auto` | `-m large` |
| `-g, --gain` | Alpha gain value (1.0-3.0) | `1.0` | `-g 1.5` |
| `-h, --help` | Display help | - | `-h` |

### Option Guide

#### `-o, --output` (Output File)
- If not specified, `_clean` is added to the original filename
- Can include directory path (directory must exist beforehand)
- Can save to different format (e.g., PNG → JPG)

#### `-m, --mode` (Mask Mode)
- **auto**: Automatically select based on image size (recommended)
  - ≤1024px: use small mask
  - >1024px: use large mask
- **small**: 48×48 mask, 32px margin (for small images)
- **large**: 96×96 mask, 64px margin (for large images)

#### `-g, --gain` (Alpha Gain)
- Controls watermark removal strength
- **1.0**: Standard removal (sufficient for most cases)
- **1.5-2.0**: For darker watermarks
- **2.0-3.0**: For very dark watermarks (may degrade image quality)

## How It Works

This tool uses a reverse alpha blending algorithm to remove watermarks.

### Algorithm

```
original_pixel = (current_pixel - α × watermark_color) / (1 - α)
```

### Processing Steps

1. **Load Image**: Load image as RAW data using Sharp library
2. **Select Mask**: Choose appropriate mask based on image size
3. **Calculate Watermark Position**: Determine position from bottom-right with margin
4. **Process Pixels**: Remove watermark from each pixel using mask alpha values
5. **Save Result**: Save processed image to specified path

### Auto-detect Mask Size

| Image Size | Mask Size | Margin | Use Case |
|-----------|-----------|--------|----------|
| ≤1024px | 48×48px | 32px | Standard resolution, web images |
| >1024px | 96×96px | 64px | High resolution, print images |

## Supported Formats

Both input and output support the following formats:
- **PNG** (recommended: lossless compression)
- **JPG/JPEG**
- **WebP**
- **TIFF**
- **GIF**

## Troubleshooting

### Watermark Not Completely Removed

1. Try increasing alpha gain value:
   ```bash
   npx gemini-image-watermark-remove image.png -g 1.5
   ```

2. Try manually changing mask mode:
   ```bash
   npx gemini-image-watermark-remove image.png -m large
   ```

### Image Quality Degradation

- Lower the alpha gain value (use default 1.0)
- Output to PNG format for lossless compression

### "Image dimensions too small" Error

- Image is too small to process watermark area
- Minimum recommended size: 128×128px or larger

### File Not Found Error

- Verify the file path is correct
- Try using absolute path instead of relative path
- Wrap filename in quotes if it contains spaces:
  ```bash
  npx gemini-image-watermark-remove "my image.png"
  ```

## Limitations

- Assumes SynthID watermark is located at bottom-right of image
- Does not work if watermark is in different location or multiple watermarks exist
- Watermarks on very complex backgrounds may not be perfectly removed
